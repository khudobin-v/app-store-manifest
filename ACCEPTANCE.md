# Приёмочный сценарий

Проверка того, что конвейер работает от команды разработчика до обновлённого
приложения на телефоне. Ручных действий ровно два: `./release.sh` и тап
«Установить/Обновить» в магазине.

## Предусловия

- репозиторий манифеста создан и публичен;
- в репозитории приложения заданы secrets `KEYSTORE_BASE64`,
  `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`, `MANIFEST_PAT`;
- `MANIFEST_REPO` в `.github/workflows/release.yml` указывает на репозиторий манифеста;
- `MANIFEST_URL` в `store-client/gradle.properties` — на его raw-ссылку;
- магазин установлен на устройство, разрешение «Установка неизвестных
  приложений» выдано.

## Шаги

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1 | в репозитории тестового приложения: `./release.sh 1.0.0 "Первый релиз"` | тег `v1.0.0` запушен, workflow запустился |
| 2 | дождаться Actions | job `release` зелёный |
| 3 | `gh release view v1.0.0` | Release создан, ассет `com.example.hellostore-1.0.0.apk` |
| 4 | открыть raw-ссылку `apps.json` | запись приложения: versionCode 1, sha256, размер, changelog |
| 5 | открыть магазин на телефоне (или потянуть список вниз) | приложение в списке, кнопка **«Установить»** |
| 6 | тап «Установить» | прогресс → «Проверка контрольной суммы» → системный диалог → установка |
| 7 | после установки | кнопка сменилась на **«Открыть»**, приложение запускается и показывает версию 1.0.0 |
| 8 | поднять `versionCode` до 2 и `versionName` до `1.1.0` в `app/build.gradle.kts`, закоммитить, запушить | — |
| 9 | `./release.sh 1.1.0 "Вторая версия"` | новый Release, `apps.json` обновлён, в `versions` две записи |
| 10 | потянуть список в магазине вниз | кнопка **«Обновить»**, подпись «1.0.0 → 1.1.0» |
| 11 | тап «Обновить» | обновление встало поверх, приложение показывает версию 1.1.0 |

## Негативные проверки

| Проверка | Как | Ожидание |
|---|---|---|
| дубликат versionCode | повторный релиз без поднятия `versionCode` | workflow падает: «versionCode уже опубликован», `apps.json` не изменился |
| грязное дерево | `./release.sh` с незакоммиченными изменениями | скрипт отказывается, тег не создаётся |
| существующий тег | `./release.sh` с уже занятой версией | скрипт отказывается |
| несовпадение версии | тег `v1.2.0` при `versionName = "1.1.0"` | workflow падает на шаге извлечения метаданных |
| битый APK | подменить `sha256` в `apps.json` вручную | клиент удаляет файл и показывает «APK повреждён или подменён» |
| офлайн | выключить сеть, открыть магазин | список из кэша с плашкой «Показан сохранённый список» |
